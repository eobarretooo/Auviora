# Roadmap

## Phase 2.0 — independent foundation (complete)
Independent Git identity, reproducible native integration, core contract, Compose design system/drawer/chat/models/agents/settings, English/pt-BR, verified provisioning and actual device validation. All engineering gates passed, including actual offline text/streaming/cancel/reload through the new UI and an independent checkout build. See [validation](testing/PHASE_02_VALIDATION.md). Production model quality is not approved.

## Phase 2.1 — presentation (complete)

Truthful English GitHub landing page, prominent pt-BR guide, seven actual device screenshots, real offline streaming GIF, reproducible media/link scripts and reorganized design documentation. No app/version/engine changes. See [report](PHASES/PHASE_02_1.md) and [future quality findings](design/ANDROID_QUALITY_BACKLOG.md).

## Next phase — not authorized
Advanced chat attachments, context restoration/history management, resilient background downloads, richer model profiles and expanded lifecycle/device tests require explicit scope. No automatic implementation.

## Later product capabilities
Persistent memory/personalized assistants and authorized agent tools require separately approved contracts, deterministic permission policy and Android API boundaries. No unrestricted automation, AccessibilityService or background replies in this foundation.
